nx-cugraph retirement
=====================

nx-cugraph was deprecated in RAPIDS 26.12, its final release. It is not
included in RAPIDS 27.02 or later. Nightly builds continue only for the
26.12 release line through its final release.

For supported GPU graph analytics, use the :doc:`cuGraph Python API
<../api_docs/cugraph/index>` directly.

The pages below describe the final release and earlier versions. Their
examples and benchmarks do not imply support with current RAPIDS packages.
