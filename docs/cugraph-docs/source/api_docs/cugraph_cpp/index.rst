libcuGraph C++ API
==================

The C++ API contains graph data structures, complete algorithms, graph
construction, sampling, and communication utilities. Lower-level
:doc:`graph primitives <../cugraph_prims/index>` and the
:doc:`libcugraph_etl API <../cugraph_etl/index>` are documented separately.
